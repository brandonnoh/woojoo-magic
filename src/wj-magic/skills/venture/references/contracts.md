# 산출 계약 — 근거 등급 · 판정 · 아이템 6필드 · 교차 검증

이 파일은 venture의 **출력 규격**이다. 워커도 코디네이터도 이 규격을 벗어나면 안 된다.
규격이 없으면 리포트를 비교할 수 없고, 비교가 안 되면 종합이 불가능하다.

---

## 1. 근거 등급 (B1) — 이게 심장이다

모든 수치·주장 앞에 등급을 붙인다. 예외 없다.

| 등급 | 의미 | 확보 방법 |
|---|---|---|
| `[실측]` | 직접 호출·측정해 확인 | curl, API 호출, 파일 다운로드, 실제 가입·결제, 스크립트 실행 |
| `[문서]` | 공식 문서에서 확인 | 개발자 문서, 약관, 공시, 정부 공고 |
| `[자체발표]` | 당사자가 홍보한 수치 | 보도자료, 회사 블로그, IR 자료, 창업자 인터뷰 |
| `[추정]` | 3자 추정 | 애널리스트 리포트, 시장조사 기관, 계산으로 역산 |
| `[미검증]` | 확인 못 함 | 예산 소진, 접근 불가, 출처 불명 |

**신뢰 순위**: `[실측]` > `[문서]` > `[자체발표]` > `[추정]` > `[미검증]`

### 왜 이게 심장인가

이 지시가 없으면 SEO 콘텐츠팜 수치를 그대로 믿는다. 실제 사례:

- 여러 매체가 인용한 *"$8B ARR"*이 다른 소스에선 **$2.5B**였다 — 둘 다 `[자체발표]`.
- *"$2B ARR"* 주장은 GMV 기준이었고 실질 순매출은 **3분의 1**이었다.
- "플랫폼이 이미 흡수했다"는 `[추정]`이었고, `[실측]`(curl 1회)로 **거짓 판정**됐다.

**판단을 뒤집은 것은 전부 실측이었다.** 그래서 워커에게 검색이 아니라 **호출**을 시킨다.

### 규칙

- `[자체발표]` 수치는 **최소 2개 독립 출처**로 교차하지 않으면 판단 근거로 쓰지 않는다.
- `[추정]`만으로 아이템을 죽이거나 살리지 않는다 — 반드시 `[실측]`/`[문서]`로 승격을 시도한다.
- 예산이 없어 확인 못 했으면 추측하지 말고 `[미검증]`으로 남긴다. **모른다고 쓰는 게 정직이다.**

## 2. 판정 문장 (B3)

모든 리포트의 **§0에 판정을 먼저** 쓴다. 본문보다 위다.

```markdown
## §0 판정

판정: "{명제}"는 ({A} / {B} / 판단 불가).
근거 등급: [실측]
한 줄 근거: {가장 결정적인 사실 하나}
```

- **양비론 금지.** "일부는 맞고 일부는 틀리다"로 끝내지 않는다. 명제를 쪼개서 각각 판정한다.
- **모르면 "판단 불가"**라고 쓴다. 이건 실패가 아니라 유효한 판정이다. 대신 무엇을 확인하면
  판정이 가능한지 한 줄로 적는다.
- 이게 없으면 리포트 5,000줄을 읽고도 결정을 못 한다.

## 3. 아이템 6필드 형식 (M1)

모든 아이템 제안은 이 형식을 벗어날 수 없다. "이런 방향이 좋겠다"는 제안이 아니다.

| 필드 | 내용 | 불합격 예 |
|---|---|---|
| **(a) 정의** | 한 문장 | "AI로 업무를 효율화하는 서비스" ← 추상적 |
| **(b) 첫 고객** | 누구이고 **어떻게 찾는가 — 채널을 실명으로** | "중소기업" ← 채널 없음 |
| **(c) 첫 매출** | 착수부터 첫 입금까지 걸리는 시간 | "빠르게" ← 숫자 없음 |
| **(d) 가격** | 구체 금액과 과금 단위 | "합리적인 가격" ← 금액 없음 |
| **(e) 실격 필터** | 항목별 통과/탈락 판정 | 통째로 "통과" ← 항목별 아님 |
| **(f) 3년 뒤** | 낙관/비관 두 시나리오 | 낙관만 ← 반대 신호 없음 |

### 합격 예시

> **(a)** 건설 현장 안전인증 서류를 자동 점검·제출하는 컴플라이언스 봇.
> **(b)** 50~300인 규모 전문건설업체 안전관리자. 대한전문건설협회 지역회 세미나 + 안전관리자
> 네이버 카페 2곳 + KOSHA 교육 수료자 대상 DM. `[실측]` 카페 회원 3.1만/1.4만.
> **(c)** 6~8주 (파일럿 2곳 무료 → 3주차 유료 전환).
> **(d)** 현장당 월 5~15만원. 현장 수 과금.
> **(e)** 온보딩 <2시간 ✅ / 콜드콜 불필요 ✅(세미나·카페 인바운드) / 인허가 불필요 ✅ / 재고 없음 ✅
> **(f)** 낙관: 3년 800현장 월 8천만. 비관: 대형 안전관리 SI가 번들로 끼워 팔면 단독 판매 소멸.

### 탈락 기록 (M3)

리포트에 **탈락 후보 표**를 반드시 남긴다. "왜 그게 아닌지"가 "왜 이건지"만큼 중요하다.

```markdown
| 탈락 후보 | 탈락 사유 | 근거 등급 |
|---|---|---|
| 시니어 케어 매칭 | 인력 파견 = 운영 중량, 실격 필터 3 위반 | [문서] |
| AI 문서 요약 툴 | 범용 LLM이 이미 무료 제공, 해자 없음 | [실측] |
```

나중에 같은 후보가 다시 떠오를 때 **재조사 비용을 0으로 만든다.**

## 4. 교차 검증 (B4) — SYNTHESIZE의 핵심

리포트 2개 이상이 쌓이면 3개 목록으로 분류한다.

### ① 독립 일치 → 신뢰도 최상
서로의 리포트를 보지 못한 워커들이 **같은 결론에 도달**한 것.

> 두 워커가 서로 모르는 채 같은 리스크를 1순위로 지목한 것이 실제 조사에서 가장 신뢰할 만한
> 결론이었다.

일치 항목은 그대로 통합 문서의 확정 사항으로 올린다.

### ② 충돌 → 근거 등급으로 판정
| 워커 A | 워커 B | 판정 |
|---|---|---|
| `[실측]` | `[추정]` | A 채택 |
| `[문서]` | `[자체발표]` | A 채택 |
| 같은 등급 | 같은 등급 | **판단 불가** → 추가 실측 명제를 만들어 INTERROGATE 1라운드 |

등급이 같은데 결론이 다르면 **어느 쪽도 채택하지 않는다.** 새 명제를 만들어 다시 심문한다.

### ③ 원본 대비 뒤집힘 → 별도 목록으로 명시
가장 중요한 산출물이다. 통합 문서 개정 시 **표로** 남긴다.

```markdown
## 원본 대비 변경 (N건)

| # | 원본 판단 | 새 판단 | 뒤집은 근거 | 등급 |
|---|---|---|---|---|
| 1 | 플랫폼이 이미 흡수했다 | 공개 API 3종 실존, 흡수 안 됨 | curl 응답 200 + 스키마 확인 | [실측] |
```

뒤집힌 전제 위에 세워졌던 아이템은 **전부 재검토 대상**이다 → DISCOVER로 전이.
