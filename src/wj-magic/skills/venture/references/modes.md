# 모드 판별 기준 & 루프 전이 규칙

venture는 4개 모드를 가진 하나의 루프다. **사용자에게 모드를 묻지 않는다.**
입력을 읽고 판별한 뒤 한 줄로 선언하고 시작한다.

## 판별 순서 (위에서부터 먼저 걸리는 것)

| # | 신호 | 모드 |
|---|---|---|
| 1 | 입력에 **이미 내려진 판단·전제**가 들어 있다 ("~라서 안 된다", "~가 흡수했다", "이 판단 맞아?", "재검토", "정말 그런가") | **INTERROGATE** |
| 2 | `docs/reports/` 등에 **리포트가 2개 이상** 쌓여 있고 사용자가 정리·비교·결론을 요구한다 | **SYNTHESIZE** |
| 3 | **아이템이 한 개로 확정**돼 있고 "어떻게 만들까 / 스펙 / 로드맵 / 시장 분석"을 요구한다 | **DESIGN** |
| 4 | 위 어디에도 안 걸린다 (아이템 없음, 후보 여럿, 막연한 가설·타겟·관심사) | **DISCOVER** |

### 판별 예시

| 사용자 입력 | 모드 | 이유 |
|---|---|---|
| "1인 개발자로 뭐 만들지 모르겠어" | DISCOVER | 아이템 없음 |
| "A랑 B 중에 뭐가 나을까" | DISCOVER | 후보 미정 → 둘 다 6필드로 세우고 필터 |
| "이 아이템 기획해줘 / 스펙 잡아줘" | DESIGN | 아이템 확정 |
| "기획서에 플랫폼이 흡수했다고 썼는데 맞아?" | INTERROGATE | 기존 판단 존재 |
| "아이데이션 해줘" (아이템 없음) | DISCOVER | 판별 4 |
| "아이데이션 해줘" (아이템 있음) | DESIGN | 판별 3 |
| "리포트들 정리해줘 / 결론이 뭐야" | SYNTHESIZE | 리포트 축적 |

**"아이데이션"이라는 단어 자체는 모드를 결정하지 않는다.** 아이템 유무가 결정한다.

## 선언 형식

```
모드: INTERROGATE — "플랫폼이 이미 흡수했다"는 기존 판단이 있으므로 실측 심문부터 시작한다.
```

한 줄이면 된다. 모드 설명을 늘어놓지 않는다.

## 루프 전이 — 언제 모드를 바꾸는가

| 지금 | 조건 | 다음 | 비고 |
|---|---|---|---|
| DISCOVER | 생존 후보 확정 | INTERROGATE | 생존 후보의 **핵심 전제**를 명제로 뽑아 즉시 심문 |
| DISCOVER | 전부 실격 | DISCOVER | 각도를 바꿔 재발굴 (같은 각도 반복 금지) |
| INTERROGATE | 전제 붕괴 | **DISCOVER** | 되돌아가는 게 정상 동작이다 |
| INTERROGATE | 전제 유지 | DESIGN | 살아남았으니 구체화 |
| DESIGN | 리서치 중 전제 흔들림 | **INTERROGATE** | 설계를 끝까지 밀지 않는다 |
| DESIGN | 스펙 완성 | SYNTHESIZE | 리포트가 2개 이상이면 |
| SYNTHESIZE | 충돌 판정 불가 | INTERROGATE | 추가 실측 명제 1라운드 |
| SYNTHESIZE | 원본 판단 뒤집힘 | DISCOVER | 뒤집힌 전제 위의 아이템 전부 재검토 |
| 아무 모드 | 종료 조건 충족 | SHIP | SKILL.md의 종료 조건 3개 참조 |

전이할 때마다 사용자에게 **한 줄로 알린다**:
> 전이: INTERROGATE → DISCOVER — "플랫폼이 흡수했다"가 [실측]으로 거짓 판정. 그 전제 위에 세운 후보 3개를 폐기하고 재발굴한다.

## 라운드 운영 (O4)

- 한 라운드 = 워커 **3~5명** 병렬 fan-out 1회.
- 명제가 6개 이상이면 **중요도 순으로 라운드를 나눈다.** 워커를 늘리지 않는다.
- 라운드 사이에만 사용자에게 짧게 방향을 확인한다. **질문을 몰아치지 않는다.**
- 라운드가 3회를 넘어가는데도 종료 조건에 못 닿으면, 사용자에게 현재 판정 상태를
  1페이지로 보고하고 **계속 돌릴지 / 범위를 좁힐지**를 묻는다.

## 진행 보고

워커가 도는 동안 진행 테이블을 갱신해 보여준다:

```
| 워커 | 검증 명제 | 상태 |
|---|---|---|
| A1 | "플랫폼이 이미 흡수했다" | ✅ 판정: 거짓 |
| A2 | "이 가격대에 지불 의사가 없다" | 🔄 실측 중 |
```

역할명이 아니라 **명제**를 적는다(B2).
