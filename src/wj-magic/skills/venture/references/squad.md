# 리서치 스쿼드 — 단계별 병렬 워커 패턴

venture의 각 단계는 여러 워커를 병렬로 fan-out해 실측 리서치를 시킨다.
Orca 오케스트레이션이 있으면 그걸 쓰고(독립 세션 = WebSearch 예산 리셋), 없으면 Agent 툴 `run_in_background: true`로 병렬 실행한다.

## 워커 프롬프트 공통 규칙 (반드시 주입)

모든 워커 프롬프트에 넣는다:

```
- WebSearch/WebFetch를 실제로 여러 번(최소 6~10회) 호출하라. 생각만 하고 멈추지 마라. 지금 바로 도구를 호출하라.
- 모든 수치에 출처 URL. 추정은 반드시 '추정'으로 표기.
- 결론은 [타겟 시장]에 바로 적용 가능한 구체안으로.
- 낙관 금지 — 반증과 리스크를 먼저 찾아라.
- (리서치만. 코드/파일 변경 금지 — Ship 단계 제외.)
```

**조기 종료 대응**: 워커가 도구 호출 0회로 멈추면(생각만 하고 종료) 반드시 재개시킨다: "너는 아직 도구를 한 번도 호출하지 않았다. 지금부터 실제로 WebSearch/WebFetch를 여러 번 호출해 끝까지 수행하고, 최종 리포트를 반환하라."

**검색 예산 소진**: WebSearch가 막히면 WebFetch로 우회 — `url="https://html.duckduckgo.com/html/?q=<검색어>"`로 페치하고 prompt로 정보 추출. Orca 워커는 새 세션이라 예산이 살아있는 경우가 많다.

**결과 수집**: 워커는 리포트를 파일로 저장하게 하고(예: `.venture-research/<name>.md`), 완료 통지를 받으면 읽어서 종합한다. 리포트 원문은 Ship 단계에서 `docs/research/`로 정리.

## Stage 1 — DIVERGE 스쿼드
후보를 벌리는 단계. 각도별로 나눠 병렬 스캔.

- **세대·트렌드 워커**: 시대상 매크로 트렌드 + 세대별(Z/M/X/시니어) 관심사·검색 신호.
- **버티컬 스캔 워커 N개**: 카테고리를 나눠(예: 취미/문화/라이프스테이지/건강/금융) 각 버티컬의 인구·시장·트렌드 방향.
- 입력이 특정 타겟이면: 그 타겟의 [지출 역산 / 페인 역산 / 공급자화 / 트렌드 교차 / 감정·관계] 각도로 아이템 후보 생성.

## Stage 2 — GROUND 스쿼드
후보에 데이터를 채우는 단계.

- **시장규모 워커**: TAM/SAM/SOM, 인구, 시장 규모·성장률.
- **수요·검색 워커**: 검색 트렌드 방향, 커뮤니티 활동량, 성장/정체/하락.
- **경쟁·WTP 워커**: 기존 플레이어, 포화도, 지불 의사 신호.
- 산출을 스코어카드로 합성(후보 × 지표, 검증/추정 등급).

## Stage 3 — FILTER 스쿼드 (필요 시)
대개 종합자(메인)가 `filters.md`로 직접 판정하지만, 관점 전환 재탐색이 필요하면:

- **벤치마크 스캔 워커**: 미국·일본 등 검증 사례 전수 스캔 → 타겟 시장 공백 매칭 (필터 5).
- **AI-해자 워커**: "AI 시대에 안 죽는 모델" 정의 후 역으로 후보 매칭 (필터 1).

## Stage 4 — PROVE 스쿼드 (승자 딥다이브, 6축)
승자 1~2개에 대해 6개 워커 병렬:

| 워커 | 산출 |
|---|---|
| 사업성·유닛이코노믹스 | TAM/SAM/SOM · CAC·LTV·전환 · 3년 시나리오 · **go/no-go 게이트** |
| 성공공식 | 인접 마켓/제품 분해 → 훔쳐올 5 / 피할 함정 |
| 디자인 토큰 | 무드 3안 → 토큰 스펙 (craft.md 연계) |
| UX | 핵심 화면 흐름 · 온보딩 마찰 제거 · 중독성 설계 |
| CX | 첫 세션 wow · 리텐션 루프 · 커뮤니티 CX |
| 그로스·마케팅 | 콜드스타트 · 채널 우선순위 · 바이럴 루프 |

+ 규제·법무가 중요한 도메인이면 **법무 워커** 추가(에스크로·라이선스·미성년·사행성 등).

## Stage 5 — CRAFT
디자인은 리서치보다 제작이라 워커보다 메인이 직접 만든다(`craft.md`). 필요 시 레퍼런스 조사 워커 1개.

## 진행 보고

병렬 워커가 도는 동안 사용자에게 진행 테이블을 갱신해 보여준다:

```
| 워커 | 역할 | 상태 |
|---|---|---|
| ... | ... | 🔄 리서치 중 / ✅ 완료 |
```

전원 완료되면 종합 → 아티팩트 발행 → 방향 확인.
